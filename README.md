# Tip Calculator

A vanilla-JavaScript tip calculator: enter a bill, pick a tip percentage
(or type your own), and get the tip and total instantly. Built from a
blank file with plain HTML, CSS, and JavaScript — no frameworks.

**Live demo → https://williambinks.github.io/tip-calculator/**

![Tip Calculator demo](screenshot.png)

## Features
- Enter any bill amount
- Preset tip buttons (10% / 15% / 20%) or a custom tip input
- Shows tip amount and final total, rounded to 2 decimal places
- Validates input — prompts you if the bill or tip is missing

## Built with
- HTML5 / CSS3
- Vanilla JavaScript (DOM events, input handling, number formatting)
- Deployed on GitHub Pages

## What I learned
My first project built from a blank file with no tutorial — wiring up
click and keyboard events, reading and coercing input values, and
handling the invalid-input cases cleanly.
